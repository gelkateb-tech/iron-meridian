How to read an entry: **the decision** in one plain line; **where** it lives (file and function or constant, or the doc); **source**: the
owner's words and date where the docs record them, "owner (date)" where a doc says the owner decided without quoting, or "in code" for a
choice that is only in the code and its comments. Numbers were read from the code; where only a doc says it, the entry says "doc".

Not in this file on purpose: anything still waiting on the owner (docs/QUEUE.md "Waiting on me"). Those are open, not settled. The planned
work of LATER.md is settled as a plan (build nothing of it in this session); see the section at the end of LATER.md.
